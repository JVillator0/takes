# Frontend rules: Inertia v3 + Vue 3 + TypeScript

Applies to: `resources/js/**`, `resources/css/**`, `vite.config.ts`, and the server side that feeds pages (`app/Http/Resources`, Inertia shared props, `lang/en/*.php`).
Sources: spec 1-01 (TS rules), 2-01 (copy and money display), 4 and 5 (workspace, live status), decisions D-021, D-023, D-028, D-033, D-042, D-057.

Each rule has an ID that reviewers cite. Default severity is **important**; rules marked **critical** block the merge.

## Tooling

- [ ] **F-01 Formatting and lint come from vite-plus (`vp`), not Prettier/ESLint configs.** `npm run check` (`vp check`: oxfmt + oxlint type-aware, `denyWarnings`) and `npm run types` (`vue-tsc --noEmit`, `strict`, `noUncheckedIndexedAccess`) must pass. The PostToolUse hook formats each edited file with `vp fmt`.
- [ ] **F-02 Do not edit generated code.** `resources/js/actions/**`, `resources/js/routes/**`, `resources/js/wayfinder/**` are generated by Wayfinder; `resources/js/components/ui/*` are shadcn-vue primitives (change them only to fix a bug, in their own commit).

## TypeScript and Vue

- [ ] **F-03 `<script setup lang="ts">` and the Composition API only.** One root element per page component (Inertia). No Options API, no mixins.
- [ ] **F-04 No `any`.** Use `unknown` and narrow. Typed `defineProps<…>()` and `defineEmits<…>()`. Shared types live in `resources/js/types/` and mirror the API resources field by field.
- [ ] **F-05 Routes through Wayfinder.** Import from `@/actions/…` or `@/routes/…`; never hardcode a URL string for an app route.
- [ ] **F-06 Composables for shared behaviour** (`resources/js/composables/use*.ts`); no business logic in templates.

## Inertia v3 patterns

- [ ] **F-07 Forms use Inertia (`useForm` or `<Form>`), errors come from the server.** No ad-hoc `fetch`/Axios for app routes (Axios is removed in v3; use `useHttp` only for non-page requests).
- [ ] **F-08 Idempotency keys are client-minted (D-033).** The composer mints `crypto.randomUUID()` per draft on mount and again after a successful submit; the same key is sent on every retry of that draft. Same for AI `request_key`. **Critical.**
- [ ] **F-09 Partial reloads and polling are scoped.** `router.reload({ only: [...] })`, `usePoll(ms, { only: [...] })`; never reload the whole page to refresh one list.
- [ ] **F-10 Live status (spec 5, D-028, D-079).** `useEcho` from `@laravel/echo-vue` on `App.Models.Customer.{id}` refreshes the card with a scoped `router.reload({ only: ['takes', 'counts', 'auth'] })` and shows the payload's balance pill until the next `auth` refresh (an older payload, by `take.updatedAt`, never replaces a newer one). The page is live only while the private channel is subscribed. Polling (`usePoll(4000, { only: ['takes', 'counts', 'auth'] })`) runs while it is not, a take is non-terminal and the tab is visible; every successful subscription (and a mount on an already-subscribed channel) triggers one catch-up reload with the same `only`. Listeners and timers are cleaned up on unmount. See webhooks.md W-20.
- [ ] **F-11 Deferred props show a skeleton**, never an empty flash.

## Money (critical)

- [ ] **F-12 Amounts arrive as strings already formatted by the server** (money.md M-20). The frontend never parses, sums, rounds, multiplies or formats an amount, and never holds an amount in a JS `number`. No `toFixed`, `Intl.NumberFormat` or `parseFloat` on money. **Critical.**
- [ ] **F-13 The right string in the right place (D-042).** Lists, cards, toasts and the balance pill show the server's 4-decimal string (exact value on hover via the exact string the server also sends). Take detail, billing page and invoices show the exact string. A rounded amount never shows 2 decimals. **Critical.**
- [ ] **F-14 Prices, not costs (D-023).** Customer UI never shows provider cost, tokens, provider names (`Pixelforge`, `Anthropic`, model ids) or margin. Spend is shown by feature: images, AI suggestions. **Critical.**
- [ ] **F-15 Price before action.** Every action that costs money shows its maximum price on the button ("Generate take · up to $x"), from the server's estimate string.

## Copy (single source, D-057)

- [ ] **F-16 UI copy comes from `lang/en/*.php`, whose only source is the spec 2-01 tables** (state, failure, denial-reason, billing and AI strings). Components read the translated strings the server shares; they never hardcode a sentence that exists in 2-01, never paraphrase it, and never restate it in another file. A copy change is made in 2-01 and the lang file together. **Critical** for money, status, failure and denial copy.
- [ ] **F-17 Status labels and denial messages are keyed by the enum value** (`TakeStatus`, `FailureCode`, `DenialReason`), never by matching English text.
- [ ] **F-18 Copy style.** Sentence case buttons ("Generate take", "Buy credits"), no em dashes, "You were not charged." on terminal failures, product nouns: take, project, remix, describe a change, credits, on hold.

## Accessibility and modern web

- [ ] **F-19 Status changes are announced** through an `aria-live="polite"` region; toasts are not the only signal.
- [ ] **F-20 Keyboard and labels.** Every control is reachable and operable by keyboard, has a visible focus style and an accessible name; dialogs trap and restore focus; icons-only buttons have `aria-label`; colour is never the only carrier of state (green charged, red failed, amber waiting also have text).
- [ ] **F-21 Use the `modern-web-guidance` skill** before building a UI pattern (dialogs, popovers, forms, tables, images, view transitions) and prefer the platform primitive it recommends over a new dependency.
- [ ] **F-22 Images** have `alt` text, explicit dimensions or aspect ratio, and lazy loading below the fold; expired provider URLs fall back to the persisted copy or the 2-01 "image unavailable" string.
- [ ] **F-23 Mobile (P10).** Same routes, stacked layout; no horizontal scroll at 360 px.
